# Hybrid CPU Scheduling Algorithm

## Overview
This project implements a Hybrid CPU Scheduling Algorithm by combining Shortest Remaining Time First (SRTF) and Round Robin scheduling techniques.

## Objective
The main objective is to reduce average turnaround time and waiting time while maintaining fairness among processes.

## Features
- Hybrid scheduling using SRTF and Round Robin
- Calculates Completion Time
- Calculates Waiting Time
- Calculates Turnaround Time
- Calculates Response Time
- Calculates Throughput

## Technologies Used
- Java
- Operating System Scheduling Algorithms

## How to Run
1. Compile the program:
   javac HybridAlgorithm1.java

2. Run the program:
   java HybridAlgorithm1
